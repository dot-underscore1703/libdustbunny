# libdustbunny
libdustbunny is the internal library compiled into the dustbunny shell.
It is not a portable library, and is not meant to be or written to be used in projects other than dustbunny.
The repo here exists for those reading the dustbunny source code, and wish to contribute to either dustbunny or this library.
If you are looking for the dustbunny shell, please see https://github.com/dot-underscore1703/dustbunnny
